# UI / 画面設計書

## 1. デザインシステム

### 1.1 デザインコンセプト

**Sakura-Cyber Light** — 桜のピンクとサイバーブルーを融合したライトテーマ。
日本の美意識とデジタルの近未来感を組み合わせた独自のビジュアルアイデンティティ。

### 1.2 カラーパレット

| CSS 変数 | 値 | 用途 |
|----------|----|------|
| `--bg` | `#fdf6ef` | ページ背景（クリーム白） |
| `--bg2` | `#f7ede3` | セクション背景 |
| `--sakura` | `#c8005a` | メインアクセント（桜ピンク） |
| `--sakura2` | `#e0006e` | ホバー時のアクセント |
| `--sakura3` | `#ffd6ec` | 薄いピンク背景 |
| `--cyber` | `#005fa8` | サブアクセント（サイバーブルー） |
| `--cyber2` | `#5200b8` | パープル系アクセント |
| `--cyber3` | `#b00040` | エラー・警告色 |

| `--text` | `#180a12` | メインテキスト |
| `--muted` | `#4a2e40` | サブテキスト |

| 用途 | フォント |
|------|----------|
| 日本語テキスト | `'Zen Kaku Gothic New', sans-serif` |

### 1.4 アニメーション・エフェクト

| エフェクト | 説明 |
|------------|------|
| カスタムカーソル | ピンクの丸カーソル + リング状トレイル |

## 2. ルーティング設計

```
/                          ← ホームページ（自己紹介）
├── /works                 ← 作品一覧
│   └── /works/$workId     ← 作品詳細
├── /login                 ← ログイン（未認証時のみ表示）
└── /admin                 ← 管理者ダッシュボード（要認証）
    ├── /admin/works       ← 作品管理一覧
    │   ├── /admin/works/new              ← 作品追加
    │   └── /admin/works/$workId/edit    ← 作品編集
    └── /admin/profile     ← プロフィール管理
```

## 3. 共通コンポーネント

### 3.1 ヘッダー (`Header`)

- **位置**: 固定ヘッダー（`position: fixed; top: 0`）
- **構成要素**:
  - ロゴ: サイト名を日英で表示（日本語はサブテキスト）
  - ナビゲーションリンク: `HOME`, `WORKS`
  - 認証済みの場合: `ADMIN` リンク + ユーザーメニュー
  - ダークモードトグルボタン
- **デザイン**: 磨りガラス効果 (`backdrop-filter: blur`)、底辺のグラデーションアニメーション

### 3.2 フッター (`Footer`)

- コピーライト表示
- SNS リンク（GitHub 等）

### 3.3 カスタムカーソル (`CustomCursor`)

- デスクトップのみ表示
- ピンクの点（メインカーソル）+ リング（トレイル）
- インタラクティブ要素にホバー時にカーソルが大きくなる

### 3.4 ページ遷移ローダー (`Loader`)

- ルート間の遷移中に表示

## 4. 画面仕様

---

### 4.1 ホームページ (`/`)

**概要**: サイトのトップページ。自己紹介・スキル・SNSリンクを表示。

#### レイアウト

```
┌──────────────────────────────────────────┐
│ [Header]                                 │
├──────────────────────────────────────────┤
│ [Hero Section]                           │
│  - システム起動風テキスト                │
│  - 名前（大見出し）                      │
│  - 肩書き・キャッチフレーズ             │
│  - 自己紹介文（bio）                     │
│  - SNS リンクボタン                      │
│  - 桜花びらアニメーション               │
├──────────────────────────────────────────┤
│ [スキル・技術スタックセクション]        │
│  - 技術タグ一覧                          │
├──────────────────────────────────────────┤
│ [注目作品セクション]                    │
│  - 最新/おすすめ作品カード（最大3件）   │
│  - 「作品を全て見る」リンク             │
├──────────────────────────────────────────┤
│ [Footer]                                 │
└──────────────────────────────────────────┘
```

#### データ

- `profile.get` でプロフィールを取得
- `works.list` で公開済み作品を取得（最大3件を Hero に表示）

### 4.2 作品一覧ページ (`/works`)

**概要**: 自作サイト・Webアプリの一覧。

#### レイアウト

```
┌──────────────────────────────────────────┐
│ [Header]                                 │
├──────────────────────────────────────────┤
│ [ページタイトル]                         │
│  "WORKS" + サブテキスト                  │
├──────────────────────────────────────────┤

│  │ [thumb] │ │ [thumb] │ │ [thumb] │  │
│  │ title   │ │ title   │ │ title   │  │
│  │ tags    │ │ tags    │ │ tags    │  │
│  └─────────┘ └─────────┘ └─────────┘  │

#### 作品カードのコンポーネント要素

- 説明文（最大2行で切り捨て）
- タグ一覧（バッジ形式）
- サイト URL / リポジトリ URL のリンクアイコン
- カードクリックで詳細ページへ遷移

### 4.6 作品管理ページ (`/admin/works`)

**概要**: 登録済み作品の一覧管理。

#### レイアウト

```
┌──────────────────────────────────────────┐
│ [Header]                                 │
├──────────────────────────────────────────┤
│ [管理サイドバー] │ [WORKS 管理]          │
│                  │                       │
│                  │ [+ 新しい作品を追加]  │
│                  │                       │
│                  │ ┌───────────────────┐ │
│                  │ │ タイトル | 状態    │ │

#### 機能

- 作品一覧テーブル（全作品、非公開含む）

- 削除ボタン → 確認ダイアログ表示後、削除実行
- 「新しい作品を追加」ボタン → `/admin/works/new` へ遷移

### 4.7 作品追加・編集フォーム (`/admin/works/new`, `/admin/works/$workId/edit`)

**概要**: 作品の作成・編集フォーム。

#### フォームフィールド

| フィールド | 入力タイプ | 必須 | 説明 |
|------------|-----------|------|------|
| 作品タイトル | text | ✓ | |
| 説明文 | textarea（Markdown） | ✓ | |
| サムネイル URL | text（URL） | - | |
| サイト URL | text（URL） | - | |
| リポジトリ URL | text（URL） | - | |
| タグ選択 | multi-select | - | 既存タグから選択・新規作成も可 |
| 公開フラグ | checkbox | - | デフォルト: 非公開 |
| 公開日時 | datetime-local | - | |
| 表示順 | number | - | |

#### 動作

- 保存成功後: `/admin/works` へリダイレクトしてトーストを表示
- バリデーションエラー時: インラインエラーメッセージを表示

## 6. 状態管理とデータフロー

### 認証状態

```
authClient.getSession()
  ├── セッションあり → 認証済みメニュー表示
  └── セッションなし → ゲストメニュー表示
```

### データフェッチ

- **TanStack Query** を利用してサーバーデータをキャッシュ
- **oRPC** の `queryOptions()` を利用してタイプセーフにデータを取得
- ミューテーション（作成・更新・削除）後は `queryClient.invalidateQueries()` でキャッシュを無効化
