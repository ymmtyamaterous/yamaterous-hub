## 6. 認証・認可

- **認証方式**: メールアドレス + パスワード（better-auth）
- **セッション管理**: Cookie ベース（`httpOnly`, `secure`, `sameSite: none`）
- **管理者判定**: ログイン済みユーザー = 管理者とみなす（単一管理者運用を前提）
- **保護ルート**: `/admin/*` は認証チェックを実施し、未認証の場合は `/login` へリダイレクト

## 7. 非機能要件

### 7.1 セキュリティ

- パスワードは better-auth によりハッシュ化して保存
- CORS 設定は環境変数 `CORS_ORIGIN` で制限
- 管理系 API は `protectedProcedure`（認証ミドルウェア）で保護
- Cookie は `httpOnly`, `secure` 属性を付与

### 7.2 パフォーマンス

- TanStack Query によるデータキャッシュ
- 静的ファイルはサーバーから配信

### 7.3 対応環境

| 種別 | 内容 |
|------|------|
| ランタイム | Bun |
| DB | SQLite（ローカルファイル） |
| ブラウザ | モダンブラウザ（Chrome / Firefox / Safari 最新版） |
| レスポンシブ | 対応（モバイル・タブレット・PC） |

### 7.4 ビルド・起動

- バックエンドサーバーのビルド成果物がフロントエンドの静的ファイルを配信する
- サーバー起動時に DB のマイグレーション・シードを自動実行する
